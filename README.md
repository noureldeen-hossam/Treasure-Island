# 🏝️ Treasure Island

A simple text-based adventure game built with Python.

The player makes a series of choices to find the hidden treasure. Choose carefully — one wrong decision and it's **Game Over!** 💀

## 🎮 How to Play

1. Choose a direction at the crossroads.
2. Decide whether to wait for a boat or swim.
3. Choose one of three doors.
4. Try to find the treasure! 💰
